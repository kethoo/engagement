# engagement

## Dataset

This project uses the data from the
**[WASSA 2024 Shared Task](https://codalab.lisn.upsaclay.fr/competitions/18810)**
(CodaLab competition 18810).

The dataset is not redistributed here — it is obtained from the competition page,
under that competition's own terms and conditions.

## Pipeline

Experiments are run with **[micm-nlp](https://nlp.micm.edu.ge/en/latest/index.html)**,
a research framework that drives a whole NLP pipeline from a single YAML config —
either one run or a group of runs — on top of the HuggingFace stack.

It is developed at the Muskhelishvili Institute of Computational Mathematics (MICM),
Georgian Technical University.
